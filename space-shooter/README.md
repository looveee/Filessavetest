# 太空射击（space-shooter）

一个用 **HTML5 Canvas + 原生 JavaScript** 从零开始、一步一步做出来的 2D 街机射击游戏。
目标是零基础也能跟着走：每个"阶段"只加一点点新东西，并且每一步都能立刻看到成果。

## 怎么玩 / 怎么看

- **在线试玩（最简单）：** 打开对话里给出的 Artifact 链接即可，无需安装任何东西。
- **本地打开：** 直接用浏览器打开本目录下的 `index.html`（双击即可）。
- **操作：** 用 `← → ↑ ↓` 方向键，或 `W A S D` 移动飞船。

> 整个游戏就是一个 `index.html` 文件，里面同时包含画面（HTML）、样式（CSS）和逻辑（JavaScript）。
> 对初学者来说，单文件最容易理解；等游戏变大了，我们再把它拆成多个文件。

## 阶段 1 学到的核心概念

1. **画布（canvas）与画笔（context）** —— 所有画面都用 `ctx` 在 canvas 上绘制。
2. **游戏主循环（game loop）** —— `requestAnimationFrame` 让"更新 → 绘制"每秒重复约 60 次，连续画面形成动画。
3. **按键状态记录** —— 用一个 `keys` 对象记录当前按住了哪些键，循环里再据此移动。
4. **用对象表示游戏实体** —— 飞船就是一个 `{x, y, size, speed}` 对象，之后子弹、敌人也都是这种思路。
5. **边界限制** —— 简单的 if 判断，防止飞船飞出屏幕。
